# SupportPilot — AI Support & Knowledge Assistant

A cloud-first portfolio project for building practical AI solutions for SaaS and support teams.

## What this project will become

SupportPilot is designed to help a support team:

- Ask questions against trusted company documentation
- Upload and manage knowledge sources
- Generate grounded answers with source references
- Classify and prioritize support tickets
- Draft responses for human review
- Automate repeatable support workflows

## Current status

**v0.1 — Foundation**

The first milestone contains the responsive application experience and the initial support/knowledge workflow UI. AI, Supabase, document ingestion, and workflow automation will be connected in later milestones.

## Planned stack

- Next.js + React + TypeScript
- Supabase for database, authentication, and knowledge storage
- LLM API for grounded AI responses
- n8n for workflow automation
- Vercel for deployment
- GitHub for source control

## Product goal

This project is being developed as a real-world AI implementation portfolio project, with the goal of turning the resulting capabilities into practical AI automation and implementation services for SaaS and SMB teams.
